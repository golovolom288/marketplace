# Описание проекта

Интернет-магазин — это веб-приложение для продажи товаров с интегрированным Telegram-ботом для взаимодействия с администраторами и подтверждения заказов.

## Основные технологии

Backend: Django

Frontend: HTML, CSS (Bootstrap), JavaScript

База данных: SQLite

Хостинг: Локальный сервер (при необходимости)

## Функционал

### 1. Пользовательский функционал

Регистрация и авторизация через электронную почту и пароль

Каталог товаров(Каталог по категориям и их подкатегориям)


Telegram-бот для оформления заказа с вводом адреса доставки и выбором оплаты, а так же подтверждение заказов и оплаты через QR-код.

### 2. Администраторский функционал

Управление товарами (добавление, редактирование, удаление)

Управление категориями товаров(добавление, редактирование, удаление, создание подкатегорий)

Управление заказами (Все заказы бот отправляет в Лс Администратору)

## Установка и запуск

### 1. Клонирование репозитория

git clone https://github.com/golovolom288/marketplace.git
cd marketplace

### 2. Установка зависимостей

Создайте и активируйте виртуальное окружение:

python -m venv venv
source venv/bin/activate  # для macOS/Linux
venv\Scripts\activate  # для Windows

Установите зависимости:

pip install -r requirements.txt

### 3. Настройка базы данных

Примените миграции для базы данных:

python(или python3) manage.py migrate

### 4. Запуск сервера

python(или python3) manage.py runserver

### 5. Запуск Telegram-бота

Укажите токен бота в .env и запустите:

python bot.py
